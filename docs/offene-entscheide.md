# Offene Entscheide

- [ ] Versand der Anfrage: Formulardienst oder eigene kleine Funktion (Phase 3). Zu prüfen sind Datenstandort, Auftragsbearbeitung, Speicherfrist.
- [ ] Repository öffentlich oder privat. GitHub Pages aus einem privaten Repository braucht ein bezahltes Konto.
- [ ] Domain: DNS bei Hostpoint umstellen (Phase 6).
- [ ] Barzahlung: Die alte Info-Seite schliesst sie aus, die AGB erlauben sie. Was gilt?
- [ ] Geschenkboxen und Catering: Was gilt?
- [ ] Liefergebiet, Vorlaufzeit und Höchstzahl Aufträge pro Tag.
- [ ] Postadresse und Telefon für Impressum und strukturierte Daten.
- [ ] Kreationen: Satz, Grössen, Personenzahl, Preise und Allergene bestätigen. Die Dateien unter `inhalt/kreationen/` tragen bisher nur den Namen.
- [ ] Bilder: Fotos für Waldmeister, Antipastizauber, Brot, Chutney und Feigensenf. Fotos mit Menschen am Tisch für den Auftakt.
- [ ] Firmenlogos und Kundenstimmen mit Einverständnis.
- [ ] Rechtstexte der bisherigen Seite übernehmen, Datenschutzerklärung prüfen lassen.
- [ ] Texte: Freigabe durch Sibylle, Kapitel für Kapitel.
- [ ] Reduziertes Zeichen für Favicon und Kleinformate.
